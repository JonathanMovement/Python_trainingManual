## -----------------------------------What is an API?-------------------------------------



### **API** stands for **Application Programming Interface**

### In simple terms: An API lets one program talk to another in a structured way. Your code sends requests and received data.



------



### Real-World Analogy



------



##### **Restaurant example** 🍽️

##### \- You -> your Python program

##### \- Menu -> the API

##### \- Kitchen -> the server/database

##### \- Waiter - > the API rules



------



## Most APIs today are web APIs meaning they work over internet, they use HTTP (Hypertext Transfer Protocol)



------



##### **HTTP Methods:**

##### \- GET - get data (weather, users, game stats etc.)

##### \- POST - send data (login info, scores, messages, etc.)

##### \- PUT - update data (profiles, inventory, etc.)

##### \- DELETE - Delete/Remove data



------



##### **Common Status Codes:**

##### \- 200 - Success

##### \- 400 - Bad request

##### \- 401 - Unauthorized

##### \- 404 - Not found

##### \- 500 - Server error



------



#### API **Request** -> API **Response**; **Requests** includes: URL (where), Method (GET, POST, etc.), Headers (extra info), sometimes data. **Response** includes status code (200, 400, 500, etc.) and Data (JSON format).
